# 截图生成说明

运行 `npm run build` 和 `npm run store:screenshots` 会加载当前构建的扩展，生成 16 种语言各五张 1280×800 PNG 和 `generated.json`，以及 `store/promo-small.png`、`store/icon-128.png`。版本从插件清单读取；未重新构建或版本与 package.json 不一致会失败。

截图使用公开测试钱包及模拟 25 PRL，不调用 send。默认输出是此目录，也可用 `PRL_QA_SCREENSHOT_OUTPUT` 指定 QA 输出目录，图标和宣传图写入该目录的上一级。

2026-10-12 的 0.3.0 验证已生成 80 张截图和两张商店图片，输出在 `out/ui-fix/store/`。生成结果和文件列表见该目录下 `screenshots/generated.json`。发布前应人工核对待提交的文字、完整地址和页面裁切；本轮没有上传或上架。

2026-10-14 按首个公开版本 0.1.0 的界面重新生成到本目录（16 种语言共 80 张，替换此前 0.2.0 的 30 张），同时更新了 `store/promo-small.png`、`store/icon-128.png`。截图前会把鼠标移到页面左上角，避免卡片带着悬停底色。本轮同样没有上传或上架。

2026-10-15 按 0.1.1 重新生成全部 80 张：图标改为 Ionicons，页脚版本为 0.1.1。没有上传或上架。

0.1.2 只在钱包设置里加了安全性说明，五种截图的界面都没有变，只是页脚仍显示 0.1.1，所以没有重新生成。
