PRL Wallet privacy / 隐私说明

Updated: 2026-10-11

The wallet encrypts recovery phrases and pending signed transactions locally. The unlock key is held in trusted extension session storage and cleared on lock. Recovery phrases, private keys and passwords are never sent to servers.

Blockbook mainnet and testnet services receive public account keys, addresses and transaction IDs for chain queries. An explicitly confirmed payment sends a signed transaction to the selected network. Rebroadcast, in a transaction’s details, sends the unconfirmed transaction the service already holds back to the network.

The pearlhub.net permission allows public market requests without wallet identity or cookies, and optional email account login and contact sync. The identity permission opens the shared sign-in page and receives a one-use PKCE callback; it does not read your Google or Microsoft account.

本机加密保存助记词与待确认交易；解锁密钥只存于可信扩展会话，锁定后清除。密码、助记词和私钥不会发给服务器。Blockbook 查询会收到公开账户公钥、地址和交易编号；用户确认付款时发送已签名交易；在交易详情点「重新广播」时，把 Blockbook 已有的那笔未确认交易再次发往网络。

pearlhub.net 权限用于公开行情及可选邮箱账号登录、通讯录同步。identity 权限用于打开统一登录页并接收一次性授权回调，不读取 Google 或 Microsoft 账号。

Contact names, public addresses and notes remain unencrypted in trusted local extension storage. Optional account sync stores email, public contacts and device metadata on Cloudflare. Configuration is encrypted at rest; the server can read it. Account credentials stay in trusted local extension storage and are independent of wallet unlock. Sign-out restores guest contacts. Account settings export and deletion are available on the account page. No Chrome account sync is used.

Only after a user clicks a web link is the selected public mainnet address placed in the URL fragment (#workers or #wallet). The initial HTTP request does not contain that fragment. The web application then receives the prefilled public address and may query it after loading. Optional donations and change consolidation use the same preview and password-confirmed local signing flow. Consolidation sends only confirmed change to your own primary address.

通讯录名称、公开地址和备注以明文存于可信插件本机存储。可选邮箱同步会在 Cloudflare 保存邮箱、公开联系人及设备信息；云端配置加密存储，服务器可以读取。账号登录凭据存于可信插件本机存储，与钱包解锁独立。退出账号恢复未登录时的联系人。账号页可导出配置、注销账号。数据不通过 Chrome 账号同步。点击网页链接才会将主网公开地址交给网页预填和查询；捐赠与找零归集仍需预览及密码确认。

No analytics, advertising, tracking, content scripts or remote executable code. Browser/network infrastructure can observe request IP addresses. Browser removal deletes local wallet data; retain your offline backup.
